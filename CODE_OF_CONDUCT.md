# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good intent, and keep criticism about the work, not the person. Harassment, insults and personal attacks are not accepted in issues, pull requests or anywhere else the project meets.

## Reporting

Report unacceptable behaviour privately to the maintainers. Open the repository's **Security** tab, choose **Report a vulnerability**, and say in the title that it is a conduct report; only the maintainers can read it. You can also use GitHub's **Report content** option on any comment.

Maintainers review every report, keep the reporter's identity private, and may edit or remove comments, or block people who break this code, as the Contributor Covenant describes.
